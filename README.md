# Планировщик задач для Windows и Telegram (Todo App)

Удобная система управления личными задачами с поддержкой **оконного графического интерфейса Windows (GUI)**, **персонального многопользовательского Telegram-бота** и **консольной строки (CLI)**.

---

## Структура проекта

```text
todo-student/
├── todo.exe              # Автономное оконное приложение для Windows
├── todo.py               # Исходный код приложения (GUI + CLI + Data Core)
├── bot.py                # Телеграм-бот с индивидуальными базами для каждого пользователя
├── .env                  # Секретный файл конфигурации (добавлен в .gitignore)
├── .env.example          # Пример файла конфигурации для репозитория
├── .gitignore            # Исключение секретов, виртуальных окружений и кэша
├── tasks.json            # Локальная база задач приложения Windows / CLI (формат JSON)
├── user_tasks/           # Папка с персональными базами Telegram-пользователей (<id>.json)
├── requirements.txt      # Зависимости для сборки EXE (PyInstaller)
└── README.md             # Документация по использованию
```

## 🤖 1. Telegram-бот (`bot.py`) с индивидуальным доступом

### 🔒 Изоляция пользователей
Каждый пользователь Telegram имеет свой **собственный, изолированный список задач**:
- Задачи разных пользователей **не смешиваются**.
- Данные каждого пользователя сохраняются в отдельный файл `user_tasks/<telegram_user_id>.json`.
- Пользователи видят только свои задачи, а нумерация ID у каждого начинается независимо.
- Локальное приложение Windows и CLI используют базу `tasks.json`.

### Как настроить и запустить:

1. **Получите токен бота**:
   - Откройте Telegram и напишите боту [@BotFather](https://t.me/BotFather);
   - Отправьте команду `/newbot`, укажите имя и юзернейм;
   - Скопируйте полученный HTTP API токен.

2. **Укажите токен в `.env`**:
   - Создайте файл `.env` (или скопируйте `.env.example` -> `.env`):
     ```env
     BOT_TOKEN=ваш_токен_здесь
     ```
   - *Файл `.env` уже внесён в `.gitignore` и защищён от попадания в Git.*
   - Также поддерживается запуск с аргументом: `python bot.py <ВАШ_ТОКЕН>` или через системную переменную окружения `BOT_TOKEN`.

3. **Возможности Telegram-бота**:
   - `📋 /list` — вывод вашего персонального списка задач с **интерактивными инлайн-кнопками**: клик по кнопке прямо в Telegram мгновенно меняет статус (`✅` / `⬜️`);
   - `➕ /add <текст>` — добавление задачи в ваш личный список;
   - **Обычные текстовые сообщения** — просто отправьте боту текст сообщения (например, *Купить чай*), и он автоматически добавит его как персональную задачу;
   - `✅ /done <id>` — отметка задачи выполненной по номеру;
   - `🗑️ /delete <id>` — удаление задачи (также доступно через инлайн-кнопку 🗑️);
   - Удобная клавиатура с кнопками быстрого доступа внизу чата.

## 🖥️ 2. Оконное приложение Windows (GUI)

- Запускается двойным кликом по файлу `todo.exe` в проводнике Windows;
- Либо через терминал:
  ```powershell
  .\todo.exe
  # или
  python todo.py
  ```

### Возможности:
- Ввод новой задачи и добавление по нажатию `Enter` или кнопке **«➕ Добавить»**;
- Переключение статуса задачи (`✅` / `⬜️`) двойным кликом, клавишей `Пробел` или кнопкой;
- Фильтрация: «Все», «Активные», «Выполненные»;
- Удаление задачи кнопкой **«🗑️ Удалить»** или клавишей `Delete`;
- Статистика в реальном времени (Всего / Выполнено / Осталось);
- Нативный дизайн с системным шрифтом `Segoe UI` и поддержкой High-DPI экранов.

## 💻 3. Консольный режим (CLI)

Для быстрой работы из PowerShell или командной строки:

- **Добавить задачу**:
  ```powershell
  python todo.py add "Купить продукты"
  ```
- **Показать список задач**:
  ```powershell
  python todo.py list
  ```
- **Отметить задачу выполненной**:
  ```powershell
  python todo.py done 1
  ```
- **Справка по командам**:
  ```powershell
  python todo.py help
  ```

## 💾 Формат хранения данных

1. **Локальные задачи (Windows / CLI)**:
   Сохраняются в файле `tasks.json`:
   ```json
   [
     {
       "id": 1,
       "text": "Купить продукты",
       "done": true
     }
   ]
   ```

2. **Персональные задачи пользователей Telegram**:
   Каждый пользователь бота получает индивидуальный файл в каталоге `user_tasks/<user_id>.json`. Это гарантирует полную приватность и независимость списков задач.

## ⚙️ Сборка exe файла для Windows

Для сборки автономного приложения `todo.exe` (без окна консоли):
```powershell
pip install -r requirements.txt
pyinstaller --onefile --noconsole --distpath . --name todo todo.py
```
