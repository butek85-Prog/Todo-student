# Планировщик задач для Windows, Telegram и Web (Todo App)

Удобная кросс-платформенная экосистема для управления личными задачами с поддержкой:
- **Оконного графического интерфейса Windows (GUI)** и автономного `todo.exe`;
- **Персонального Telegram-бота** с изолированными списками задач для каждого пользователя;
- **Веб-интерфейса (Web App / Telegram Mini App)** с современным дизайном и интерактивным управлением;
- **Консольного интерфейса (CLI)** для быстрой работы из терминала.

Все компоненты синхронизированы в реальном времени через локальные JSON-базы.

## 🚀 Быстрый запуск

### Единый запуск (Бот + Веб-интерфейс):
Просто запустите файл **`run_all.bat`** (двойным кликом в Проводнике Windows).  
Он автоматически откроет окно Telegram-бота, запустит веб-сервер и откроет страницу планировщика в вашем браузере.

---

## 🤖 1. Telegram-бот (`bot.py`)

### 🔒 Персональные списки задач
Каждый пользователь Telegram получает свой **собственный, изолированный список задач**:
- Задачи разных пользователей не перемешиваются.
- Данные сохраняются в `user_tasks/<telegram_user_id>.json`.
- Нумерация задач у каждого пользователя начинается независимо с 1.

### Настройка и запуск бота:
1. Получите токен у [@BotFather](https://t.me/BotFather) в Telegram.
2. Укажите токен в файле `.env`:
   ```env
   BOT_TOKEN=ваш_токен_здесь
   DEFAULT_USER_ID=5265404800
   WEBAPP_URL=
   ```
3. Запустите бота через `run_bot.bat` или команду:
   ```powershell
   python bot.py
   ```

### Возможности бота:
- `📋 /list` — вывод списка задач с **интерактивными инлайн-кнопками** (клик по кнопке прямо в Telegram переключает `✅` / `⬜️`);
- `➕ /add <текст>` — добавление задачи (или просто отправьте боту текст обычным сообщением);
- `✅ /done <id>` — отметка выполнения по номеру;
- `🗑️ /delete <id>` — удаление задачи;
- `🌐 Открыть веб-приложение` — при указании `WEBAPP_URL` в `.env` кнопка появляется прямо в меню бота.

## 🌐 2. Веб-приложение (`run_web.bat`)

Запускается двойным кликом по `run_web.bat` (или `python web_app.py`):
- Автоматически открывает `http://localhost:5000` в браузере;
- Синхронизировано с задачами вашего Telegram-бота (по умолчанию открывает ваш профиль `DEFAULT_USER_ID`);
- В правом верхнем углу доступен выпадающий список для быстрого переключения между базами данных;
- Поддерживает добавление, удаление, редактирование, фильтрацию и поиск задач;
- Имеет встроенный интерактивный веб-эмулятор Telegram-бота.

---

## 🖥️ 3. Оконное приложение Windows (`todo.exe`)

- Запускается двойным кликом по `todo.exe` в Проводнике Windows;
- Работает автономно (Python на компьютере не требуется);
- Нативный интерфейс на шрифте `Segoe UI` с поддержкой High-DPI экранов;
- Отображает актуальные задачи и мгновенно сохраняет изменения.

---

## 💻 4. Консольный режим (CLI)

Для быстрой работы из терминала:
```powershell
# Добавить задачу
python todo.py add "Купить продукты"

# Показать список
python todo.py list

# Отметить выполненной
python todo.py done 1

# Справка
python todo.py help
```

## 🔄 Синхронизация данных

Все интерфейсы объединены:
- Параметр `DEFAULT_USER_ID` в файле `.env` привязывает десктопное приложение (`todo.exe`, `todo.py`) и веб-версию к вашему Telegram-аккаунту;
- Любая задача, созданная в Telegram, сразу видна на компьютере и в браузере, и наоборот.
