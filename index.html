ℹ️ О веб-приложении

Данная веб-страница представляет собой полноценное переосмысление консольного и Telegram-бота планировщика задач в виде интерактивного современного веб-приложения.

Она полностью совместима с существующими файлами базы данных:

  • Общие задачи: файл tasks.json (используется Windows GUI todo.exe, CLI и общим режимом);
  • Персональные задачи Telegram: файлы в папке user_tasks/<user_id>.json. Каждый пользователь получает свой изолированный список;
  • Выбор профиля: в правом верхнем углу вы можете мгновенно переключаться между базой tasks.json и персональными Telegram-пользователями!

⚡ Как запустить веб-сервер:

Веб-сервер работает без каких-либо сторонних библиотек на стандартном Python 3:

python web_app.py
# или дважды кликните по run_web.bat

🤖 Команды чата Telegram бота:

  • /start — приветствие и запуск бота с персональной клавиатурой;
  • /list — вывод персонального списка с кликабельными инлайн-кнопками;
  • /add <текст> — добавление новой задачи;
  • /done <id> — отметка задачи как выполненной;
  • /delete <id> — удаление задачи;
  • Обычный текст — просто отправьте текст задачи в чат, и бот сразу добавит её!

🔌 Доступные REST API эндпоинты:

Метод Путь Описание
GET /api/tasks?user_id=... Получение списка задач и статистики
POST /api/tasks Создание новой задачи ({"text": "...", "user_id": "..."})
POST /api/tasks/<id>/toggle Переключение статуса задачи (выполнена / активна)
POST /api/tasks/<id>/edit Редактирование текста задачи ({"text": "..."})
DELETE /api/tasks/<id>?user_id=... Удаление задачи по её идентификатору
POST /api/tasks/clear-completed Удаление всех завершенных задач
GET /api/users Список доступных профилей пользователей из user_tasks/
POST /api/bot/chat Отправка сообщения/команды в логику Telegram-бота
POST /api/bot/callback Обработка нажатий на инлайн-кнопки бота
👤 Укажите Telegram ID или имя профиля

Будет создан или открыт персональный список задач в user_tasks/<id>.json.
